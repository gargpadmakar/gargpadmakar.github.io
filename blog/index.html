About the author

Padmakar Garg is an Android developer who has spent eight-plus years shipping production apps, with 120+ published on Google Play, from e-commerce and CRM to news, astrology and secure messaging.

Since August 2022 he has been a Senior Android Developer at Sveltetech Technology, working on real-time messaging, WebRTC voice and video calling, and end-to-end encrypted communication.

Outside client work he publishes open-source Android libraries and writes on Medium and dev.to about system design, mobile security and CI/CD. His work also covers Java and Kotlin app development, Jetpack Compose, code obfuscation, and mobile device management (MDM) with Microsoft Intune.

Open source and featured projects

Enterprise Android SecureSDK

Runtime application self-protection (RASP) ecosystem for Android: an SDK with root and emulator detection, Frida and hook detection, anti-tamper checks, biometric and behavioural signals, and device risk scoring. A Spring Boot backend and React dashboard deliver remote security policies over the air and receive AES-GCM encrypted threat telemetry.

Kotlin · C++ (NDK) · Spring Boot · React

MTProtoCrypto

Kotlin cryptography SDK for Android implementing MTProto 2.0 primitives, AES-IGE, key derivation, Diffie-Hellman key exchange and media encryption.

Kotlin · Compose · Clean Architecture

screen-analytics-android

Offline-first screen analytics SDK for Android, with Compose and XML samples and no boilerplate.

Kotlin · Compose · Navigation

SvelteShield EDR

Enterprise Android endpoint detection and response: root, emulator and hooking (Frida, Xposed) detection, loopback-VPN traffic inspection, malicious IP, domain and APK blocking, and policy-driven enforcement.

Java · C/C++ (NDK) · JNI · OkHttp

AppProtectGuard

Open-source Android security project built around practical application protection and secure development.

Android · Security
